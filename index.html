Game QA Notes

Practical notes for people who test live games.

This site collects what I have learned from playing and testing games: how to check a release without missing obvious problems, which parts of a game break most often, and how to describe a bug so that a developer can fix it quickly.

Why this site exists

A good test is not about clicking every button. It is about asking the right questions: what can the player do here, what happens when it fails, and how would we know something went wrong? These notes are my attempt to write those questions down.

If you are new to game testing, start with the checklist. If you already test live games, the version notes may be a quicker read.
