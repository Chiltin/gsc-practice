A practical QA checklist for live game updates

A short list you can actually finish before a release.

Before testing

  • Read the patch notes and write down what changed.
  • Check that you are on the right build, server and account.
  • Prepare test data: a new account, a mid-level account, and an account with items.

Smoke test first

  • Can you log in, enter the game and reach the main screen?
  • Can you start a match or open the main feature that changed?
  • Does the game save progress and reload correctly?

Test the core loop

  • Play one full round from start to reward screen.
  • Check currency, items and progress after the round.
  • Repeat the same action twice to see if rewards are duplicated.

Test the edges

  • Empty input, very long input and invalid input.
  • No network, slow network and a disconnect in the middle of an action.
  • Low inventory, full inventory and a nearly full backpack.
  • Two devices logged in with the same account.

Before release

  • Re-run every bug that was fixed in this build.
  • Check the store, payment and reward flows one more time.
  • Write down what was tested, what was not, and what is still open.
