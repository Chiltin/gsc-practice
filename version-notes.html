What to watch in every game version update

Four areas that account for most of the bugs I see.

1. UI state after leaving a scene

Menus, buffs and skill effects are easy to leave behind. When a player leaves a match or a dungeon, check whether the interface still shows state from the previous scene.

2. Economy and rewards

Any change to rewards, prices or drop rates should be tested twice. Look for duplicated rewards, missing rewards, and values that do not match the design. A single duplicated reward can turn into a real loss.

3. Network and reconnects

Test what happens when the network drops in the middle of an action. The important question is not only whether the client recovers, but whether the server state is still correct.

4. Platform-specific behavior

Mobile and PC builds can behave differently: screen size, performance, payment channels and login methods. A feature that works on one platform is not automatically tested on the other.
